# LetsfixThis Docs

Welcome to LetsfixThis. See the main README for full details.

## Quick Start

```
npm install -g letsfixthis
letsfixthis start
letsfixthis analyze --format detailed
```

## Providers
- OpenAI (default)
- Cerebras via OpenAI-compatible endpoint (set provider-scoped keys)
- Anthropic (optional for Vercel AI)
